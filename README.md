# Python Data Analysis Projects
Practical end-to-end data pipeline projects built with Python, Pandas, NumPy, and Matplotlib.

## Projects
- **01. Personal Monthly Expense Analyzer:** Cleans raw transaction logs, extracts spending statistics (mean, median, 80th-percentile outliers), and visualizes category totals and cumulative monthly spend.
- **02. E-Commerce Store Performance Audit:** Cleans duplicate transactions, filters canceled orders with negative quantities, computes derived gross revenue, and visualizes product-level sales and regional performance.
- **03. Daily Health & Step Tracker:** Handles zero-reading sensor anomalies using median imputation, tracks a 3-day rolling average against activity targets, and evaluates Pearson correlation between sleep duration and resting heart rate.
- **04. RBI Policy Rate & CPI Inflation Transmission Tracker:** Analyzes macroeconomic time-series data against the RBI Monetary Policy Committee (MPC) 2%–6% tolerance band and 4% medium-term target, computes the real policy repo rate, and visualizes inflation breach dynamics alongside real interest rate trajectories.
