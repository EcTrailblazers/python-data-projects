# Python Data Analysis Projects
Practical end-to-end data pipeline projects built with Python, Pandas, NumPy, and Matplotlib.

## Projects
- **01. Personal Monthly Expense Analyzer:** Cleans raw transaction logs, extracts spending statistics (mean, median, 80th-percentile outliers), and visualizes category totals and cumulative monthly spend.
- **02. E-Commerce Store Performance Audit:** Cleans duplicate transactions, filters canceled orders with negative quantities, computes derived gross revenue, and visualizes product-level sales and regional performance.
